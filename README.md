# Visual Art Website

Starter project for Visual Art — Bright Luxury Cinematic one-page photography landing page.

## Upload to GitHub
1. Open your GitHub repository: `visual-art-website`.
2. Upload all files from this folder.
3. Commit changes.
4. Vercel will deploy automatically.

## Tech
- Next.js
- Tailwind CSS
- Framer Motion
- Lucide React

## Notes
- Current images are demo images from Unsplash.
- Prices are not displayed.
- Contact form is visual only in this version. Later we will connect it to email/WhatsApp/CRM.
